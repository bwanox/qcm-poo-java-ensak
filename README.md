# QCM POO Java - ENSA Kénitra

QCM interactif complet basé sur le cours de Programmation Orientée Objet Java de **Pr. Aniss Moumen** (ENSA Kénitra).

## Fonctionnalités
- Couvre toutes les notions : Introduction POO, UML, architecture Java, classes, objets, encapsulation, méthodes, constructeurs, packages et hiérarchie/héritage.
- Design responsive optimisé pour mobile et bureau (Tailwind CSS).
- Correction détaillée avec explications pédagogiques en français pour chaque question.
- Suivi du score en temps réel.

## Déploiement sur GitHub Pages

1. Créez un nouveau dépôt vide sur GitHub (ex: `qcm-poo-java`).
2. Exécutez les commandes suivantes dans votre terminal :
   ```bash
   cd qcm-poo-java
   git remote add origin https://github.com/VOTRE_USERNAME/qcm-poo-java.git
   git branch -M main
   git push -u origin main
   ```
3. Allez dans les paramètres de votre dépôt sur GitHub -> **Pages** -> Source : `main` branch (root `/`), et sauvegardez. Votre application sera en ligne !
